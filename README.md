# Banking Data Analysis

## Ziel

In diesem Projekt werden Banktransaktionen mit Python, Pandas und SQL analysiert.

Die zentrale Frage lautet:

**Welche Kunden und Transaktionen weisen auffällige Muster auf?**

## Technologien

- Python
- Pandas
- SQLite
- SQL
- Matplotlib
- Jupyter Notebook
## Workflow

CSV-Datei  
↓  
Datenbereinigung mit Pandas  
↓  
SQLite-Datenbank  
↓  
SQL-Abfragen  
↓  
Analyse  
↓  
Visualisierung  
↓  
Ergebnisse

## Analyse

Das Projekt untersucht unter anderem:
- Anzahl der Transaktionen
- Gesamtbetrag der Transaktionen
- Transaktionsarten
- Transaktionsvolumen pro Kunde
- ungewöhnlich hohe Transaktionen

Für die Analyse wurden Transaktionen über 3.000 Euro als auffällig definiert.

Dieser Schwellenwert ist eine einfache Analyse-Regel und stellt keinen Nachweis von Betrug dar.

## Ergebnis

Die Kombination aus Python, Pandas und SQL ermöglicht es,
Transaktionsdaten zu bereinigen, strukturiert zu speichern,
zu analysieren und visuell darzustellen.

Das Projekt zeigt grundlegende Kenntnisse in Datenanalyse,
SQL und Datenverarbeitung.s
